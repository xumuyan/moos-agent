# N01-D3：消息气泡与工具卡

接在侧栏三态后，本轮只调整独立 NSH 候选的对话区，输入框和背景不改。对照本机 Maid Atelier 0.3.2 `patches.css` 1964–1991 行的对话气泡配色、细金边与提示方向，以及 2003–2011 行的披露行浅／深色渐变；没有读取正式对话或运行皮肤 hooks。沿用已核实的来源清单 `SKIN-SOURCE.md`，仅本机取证，素材不发布。

- 用户消息右对齐、PI 公开文本左对齐，两种气泡保留相反的小底角，去掉重复角色标题，保留可选中的 Markdown、系统中文正文字体和代码样式。状态仍是独立文本，不伪装成助手内容。
- 工具事件在原顺序逐条显示，使用紧凑的 8pt 圆角渐变卡；普通、完成和失败除颜色外明确写有“开始 / 完成 / 失败”。“开始”是**历史事件**，不声称该工具仍在运行。只接受控制器对已验证公开事件的精确投影，不把用户或助手文本里的相似内容转成工具卡。
- 只用公有投影中的工具名与阶段，不显示参数、命令内容或隐藏推理；不提供虚假的折叠按钮。不引入每行背景取样模糊、动画或新模型请求。保持稳定列表记录，复用视图时行类型、文本和样式跟随当前行。

验证入口：`node --test probes/nsh-validation/desktop-message-rows.test.mjs`、`node probes/nsh-validation/verify-desktop-theme.mjs --chat-cards`（可显式加 `--art-root`）。专项验证明暗、宽窄、三类状态、停止并排空、切会话后隔离及返回显示；`--rich` 另验长 Markdown、滚动偏移、重排及最后错误行的可达性。查看 `desktop-chat-cards-verification.json` 与操作日志。合成桥接截图不构成真实 PI、人工鼠标键盘、缩放或资源比较验收，没有安装或部署。
