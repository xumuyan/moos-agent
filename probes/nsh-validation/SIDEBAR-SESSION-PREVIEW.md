# N01-D3｜项目会话悬停卡

用户截图作为交互参考，不复制其中真实目录、会话或任务信息。在独立候选的项目树中，鼠标移到任一已加载会话行，立即以和其他控件一致的蓝色圆角底绘制悬停态。停留 500ms 后用 NSH 原生 `Tooltip` 在右侧显示深色圆角卡；移出、Esc 或点击关闭。卡片不截获鼠标，不改变行高、选中状态或原点击行为；不新增归档、置顶等动作。

卡片显示对应行的标题、可用的工作区相对位置、会话创建时间和此会话已知的任务状态。独立 Host 的 `sessions.list/create` 仅返回隔离根下的 `workspace-N` 与 SQLite 创建时间，不传绝对路径、消息或凭据，也不新增 RPC、请求字段或权限。旧 Host 没有预览元数据时省略相应行；没有已知任务时不显示状态，终态未排空时不提前显示已完成/已停止。工作区有界、分项目分会话校验；工作区长文本允许两行。实时来源只涵盖本次候选进程已观察到的任务，不冒充历史恢复或正式会话最后更新时间。
