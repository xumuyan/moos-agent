# NSH 桌面候选设置

左下角「设置」打开居中的蓝金面板。外观支持跟随系统、浅色和深色，切换立即生效；人物开关只控制两侧插画及侧栏小人物，不影响背景或边饰；统计开关只隐藏输入栏统计，已排空的任务仍继续计入。没有授权本机插画的预览中，人物开关禁用。

默认模型取自现有候选 Host 的 `projects.list` 模型目录，只读；目录未提供默认项时显示「暂未提供」。输入栏仍负责当前会话的模型和推理等级。设置为当前运行的界面状态，不新增 RPC、读取正式配置或写入偏好。关闭按钮和 Esc 可关闭面板，不清空输入草稿。

## 验证

`node probes/nsh-validation/verify-desktop-theme.mjs --settings` 在 macOS 27.0.1 arm64 的 NSH 0.5.0 AppKit 开发宿主运行。授权素材 `run-YHRgCT`、无素材 `run-3jmPiF` 各 3/3、各 6 帧。两个窗口分别从 1240×820 浅色和 680×720 深色开始，在各自窗口切换到相反颜色；覆盖显式外观不随模拟系统变化、恢复跟随后响应变化、Esc 和按钮关闭、草稿保留、人物和统计切换、无素材禁用、无偏好写入。合成任务在隐藏统计时完成并排空，重新显示后仍显示 `1 轮 2 步`、`84.4%` 和 `86,416 / 128,000`。截图、命令结果及输入哈希见 `desktop-settings-verification.json`，图片和素材不入 Git。

这不是人工 GUI、焦点循环、IME、2×、真实 PI＋GUI、外部模型、签名分发或用户视觉签收。默认模型验证使用合成目录，缺省文案未单独走原生交互。没有安装、替换、重启或部署正式沐码，手机工作暂停。N01-D1/D2/D3 继续未完成。
