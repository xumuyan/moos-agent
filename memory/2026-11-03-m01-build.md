# M01 macOS 27 构建排查

- 症状：release 构建报 E0463，称无法找到 zerofrom_derive 等宏依赖，实际 dylib 已存在。
- 根因证据：ctypes.CDLL 加载原 dylib 返回 mis-aligned LINKEDIT string pool；这不是依赖下载缺失。release 的 strip=true 传播到构建期宏动态库，当前 macOS 动态加载器拒绝该产物。
- 修复：Cargo.toml 增加 profile.release.build-override.strip=false，保留主程序的 release 符号剥离。
- 验证：新生成的 zerofrom_derive dylib 可 dlopen；同一 Tauri release 构建成功，完整 .app 可运行离线 PI 验证。旧产物未删除，仍可复现加载失败。
- 回归：npm run build:probe 是该问题的实际回归入口；运行环境见 probes/m01/README.md。未修改全局 Rust 工具链。
- 其他构建处理：Tauri CLI 必须从探针工程目录运行；补充缺失图标；Swift helper 与 Tauri 统一 macOS 14 声明目标，避免 helper 随本机 SDK 默认要求 macOS 27。
- 状态：DONE_WITH_CONCERNS，当前主机打包及运行已通过，其他系统版本未验收。
- 上游参考：https://github.com/rust-lang/rust/issues/157750
