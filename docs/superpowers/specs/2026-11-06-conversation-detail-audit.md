# 会话细节审查与完善

本轮在 Mac 原生窗口重新采集关闭过程、展开工具两步截图，并与用户提供的 Codex 卡片参考共同查看。用户已确认背景保留，继续以截图中的卡片、层次和交错过程为目标。

发现的问题：失败/停止且没有最终回复的轮次仍有过多留白；过程文字和状态偏淡，命令图标不区分类型；命令行只剩重复“运行命令”；常规事件页 50 条导致较早任务无法展示完整交错过程，单改 CSS 不能解决这一点。

本轮调整：无结果的终止轮次使用更紧凑间距；增强工具卡片边界、字号和状态对比度；使用图标库的真实命令/文件/搜索/编辑及下拉图标，文件名省略时提供完整路径提示，文件卡片保留三项展开与清晰标题图标；仅有文件清单时移除首项多余上边距。既有背景/正文与单任务停止不变。

新增只读 taskTimeline v1 视图，复用 snapshot 方法，通过 conversationId/taskId 验证归属，游标必须属于同一任务。每页扫描最多 200 条，公开事件数据上限 96KiB；不返回代码、命令参数或工具原始输出，仅返回公开文字、工具信息、路径和固定白名单命令摘要。超大记录标注 limited 并推进游标，不把省略内容当完整。

客户端最近八个任务自动加载，其他轮次按展开加载；所有挂载轮次共用一个串行历史读取队列，避免同时发起补载挤满原生宿主的有界写队列，失败和已卸载轮次均释放队列；活跃任务从上次游标增量读取并与快照去重。每批最多 32 页，每轮缓存最多 10000 条/2MiB，批次未完可手动继续，达到总上限保留部分标记；跨任务迟到回复丢弃，错误可重试，旧服务可回退原快照。未加载完或达到上限时，文件清单说明只含已加载的确认修改。无法完整对应持久回复仍使用既有降级，不编造缺失历史。

验收包含超过 50 条历史、页与字节边界、跨会话/项目及游标隔离、命令摘要脱敏、增量/去重/迟到回复、32 页停批及手动继续，以及全部回归。Mac 安装版对照本轮前后截图实际检查历史过程还原、命令摘要、卡片/留白与折叠。截图和审查笔记仅保存在本机临时审查目录，不进入 Git 或原始日志；仓库证据仅脱敏结果。本轮不宣称全量无障碍合规、原生重试/撤销/完整 diff 或任意长度过程全部加载。
