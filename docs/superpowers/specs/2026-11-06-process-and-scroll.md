# 源码参考落地：统一过程入口、工具分组与滚动

用户在源码核对后确认继续。参考 DSH fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159 的 TurnProcessNodeView、ChatView/use-chat-scroll 和 OpenCode 21eaa626a37f77d7a8d80fa01997fa7d52506c97 的 BasicTool、tool-renderer、session-timeline。独立适配 React 与 Moos 事件，不引入原版服务、不伪造时长或推理。

状态和过程统一为一个入口：真实状态加操作数量，结束默认折叠，运行时展开并保留单任务停止按钮；错误内容与错误码在同一入口内查看，不再单列右上状态和第二个错误开关。没有工具、错误的任务只展示不可折叠的真实状态。最终回复与文件清单保持原有顺序。

按相邻工具的视觉类型分组：读取/浏览、搜索、编辑、命令及其他工具；只合并相邻同组，保持执行顺序及每项真实完成/失败状态，不展示参数、原始输出或代码。Shell 文件统计边界保持可查。

滚动容器独立管理跟随状态。距底部 32px 内视为跟随，新增内容跟随底部；用户上翻后不抢回，提供返回最新消息。较早历史页不自动跟随。手动折叠前保存可见锚点，在布局后恢复；内容缩短时优先保留仍存在的可见锚点。无可用锚点或内容短于视口时受浏览器滚动范围限制，不承诺任意折叠绝对无位移。没有移植 DSH 的空白预留与完整折叠动画系统。

测试覆盖：工具分组与顺序、单入口错误/取消状态与停止、流式增长跟随和上翻停跟随、返回底部、历史切换、锚点恢复；现有全量回归与 Mac 安装版手工查看入口、分组、折叠、上翻和返回按钮。新增流式数据的几何行为用可控 ResizeObserver 测试，不发送新的收费模型任务。
