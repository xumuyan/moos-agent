# 开发工作台：去除右栏，整理对话内容

用户在工作台落地后明确要求去掉右侧栏，内容也参考其他项目模式。此要求替代此前四区布局中的常驻右栏；左侧项目工具栏与工作区会话侧栏保留，中央成为完整对话区域。文件清单继续跟随所属任务显示在对话中，避免跨轮混淆。

本轮以用户已确认的 Codex 式简短过程、最终结果与修改文件模式为边界：正文使用无气泡的 Markdown 标题、段落、列表、表格和行内文件名排版，流式与持久消息共用渲染器。过程保留可折叠真实动作，任务标题改为简短状态，结束后过程默认折叠；错误与停止仍如实展示。保留代码块省略规则，缩进代码同样省略；用户输入保持原文。

参考核对：DeepSeek Harness `AssistantNodeView.tsx`、`AssistantMarkdown.tsx` 的正文/过程分工与 Markdown 表格验收，及 OpenCode 官方产品页面。只参考呈现方式，不移植其服务端、不生成不存在的模型推理、diff 行数或测试结果。

Markdown 通过 React 节点渲染，禁止执行原始 HTML；图片只显示说明，链接暂以文字引用呈现，避免自动加载外部内容或使 WebView 离开应用。右栏插件槽注册边界仍保留在代码中，但主界面不挂载，后续插件管理需明确选择其他显示位置。

验收覆盖：主界面无右栏和开关；每轮文件归属正确；正文格式及代码/HTML/图片边界；现有全量测试与 Mac 安装版实际查看。Git、终端、Shell 文件变化统计等既有未完成项保持原状态。
