# 会话区紧凑化

根据用户截图调整中央会话区，沿用既定工作台配色和简短过程模式。去除用户气泡上重复的“你”标签，消息/任务外边距统一，保留正文可读宽度，减少连续消息间的留白。输入区缩减内边距，发送按钮改为向上箭头并保留无障碍名称与提示。

失败使用一条真实状态替代重复“失败”标题与通栏红框；原始错误和错误码保留在“查看错误详情”中，默认折叠。停止、完成、运行仍依据后端实际状态；运行中单任务停止行为不变。

执行过程保持结束折叠，展开时呈现轻量竖线短动作；仅 Shell 操作的统计说明移入过程详情，存在文件汇总时仍在汇总下方显示不含命令修改的边界。文件清单与正文按原有任务归属组织，不修改历史数据、不处理模型调用失败根因。

验收：失败详情展开/错误码、运行停止与取消状态、Shell 说明可见性测试，原有全部回归与 Mac 安装版消息间距/输入区/详情折叠核对。本次不增加自动重试或新收费模型任务。
