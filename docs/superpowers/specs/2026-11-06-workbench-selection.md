# 开发工作台：已选视觉方案

用户从三版预览中选择“开发工作台”，并在预览中把窗口圆角调整为 20px。

实施范围：左侧 54px 项目工具栏连接真实项目切换、添加项目、设置；190px 工作区/会话侧栏；中间对话及底部紧凑输入区；248px 右侧本轮修改清单，支持原有收起/恢复。右栏绑定当前会话正在执行或当前历史页最近任务，成功 write/edit 列出文件和修改类型；无确认修改显示空态，命令变化未统计时说明边界，不合成测试通过状态。

默认使用预览中的暖灰底色、低饱和棕色强调、20px 窗口/设置圆角和紧凑输入框。首次切换方案清除旧皮肤偏好一次，使所选配色生效；之后用户选皮肤会继续保留。1180px 以下隐藏右栏，聊天中的文件汇总保留，项目工具栏与会话切换继续可用。

延续之前的简短执行过程、结束自动折叠、代码块省略、悬停显示滚动条、插件 Slot 与本地私有密钥存储。不实现预览中未落地的 Git 行数统计、撤销、终端或自动验证结论；OpenCode/DSH 仅作为设计参考，不引入它们的服务端。

验收：项目工具栏实际路由测试、右栏失败操作排除测试、首次主题迁移与后续皮肤保留测试、全部回归、打包 GUI 查看布局、设置入口及右栏收起/恢复；记录真实完成范围，保留窄屏未实测限制。
