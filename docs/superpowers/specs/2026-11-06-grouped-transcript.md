# 参考项目的按轮会话展示

用户再次要求参考其他项目的显示方式，本轮将上一版仅调整间距的实现推进为消息结构调整。参考已读取的 DeepSeek Harness `packages/client/ui-chat/src/client/chat/AssistantNodeView.tsx`、`MessageItem.module.css` 中按轮归属、正文/过程分层及右侧用户消息宽度约束，结合用户 Codex 截图。OpenCode 官方文档核对入口 https://opencode.ai/docs/zh-cn/；GitHub 目录浏览本次连接失败，不声称完成其源码逐像素移植。

每轮作为一个整体：右侧有限宽度用户提问 → Moos 身份/真实状态 → 可折叠过程 → 无气泡最终回复 → 修改文件卡片。轮间使用轻分隔，身份和状态只出现一次；文件清单移到回复之后。失败和停止保留在本轮，当前页未收到最终回复时显示明确空态，不留下只有一个状态的小块，不生成模型回答。

消息顺序决定轮次顺序，不使用任务快照的新到旧排序覆盖；流式消息保存后仅显示持久回复。分页缺失用户消息时保留真实 task.message，独立历史消息不丢失。工具事件继续核对项目、会话和任务归属。插件消息/工具 Slot 保持调用，未增加运行时服务。

本轮不更换主题和侧栏，不恢复右栏，不增加未经实现的复制、重试、撤销、diff 或行数按钮。沿用正文代码省略与 Markdown 边界、Shell 文件统计限制。验收含分组/顺序/分页缺失、文件末尾展示、外部项目事件排除、停止无回复空态、全部回归及 Mac 安装版结构核对。
