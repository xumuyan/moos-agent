# 会话重命名与侧栏入口整理

用户要求会话名称可修改，并移除截图侧栏底部与最左侧重复的设置入口；保持现有背景、会话卡片和插件能力。

会话行右侧提供重命名按钮，鼠标移入或键盘聚焦时显示，避免嵌套按钮；弹窗预填原名称，Enter/保存提交，取消不写入。名称去除首尾空白，非空、最多200个UTF-16代码单元，拒绝控制字符。保存中禁止重复提交；失败保留编辑内容并可重试，断连禁用写入，切换项目关闭编辑框。

新增rename_conversation经类型化UI适配、原生公开方法白名单和本地控制器进入Store。请求携带projectId/conversationId/title并验证归属和元数据预算，只更新title；ID、创建时间、任务、消息、PI会话和用量归属不变，运行中的会话允许改名。SQLite保存后刷新列表与顶部标题，重启保持。旧数据库无需迁移。

仅删除sidebar-footer中的重复设置按钮；最左ProjectRail设置入口、sidebar.primary/sidebar.footer、conversation.header/message/tool、composer.leading/trailing、settings.section/usage.metric现有Slot保持。用户之前移除的右栏继续不显示，注册的插件只有目标区域实际挂载时才可见。插件仍遵守现有Manifest/Worker声明式API与主题Token边界，不将任意页面或后端功能宣称可插件化。

验收：Store名称/边界/归属/持久化及历史保留、控制器快照、原生方法、UI适配命令、重命名交互/失败重试/取消/项目切换、App标题刷新与单一设置入口；全部回归。Mac安装版临时改名验证后恢复原名，正常重启核对；从最左入口进入设置，停用/启用内置插件观察实际输入区贡献变化并恢复初始状态。插件与皮肤的原有自动回归继续执行，不将内置插件开关等同于任意第三方安全性。
