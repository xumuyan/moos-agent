## 方案选择

采用原版展示层及布局算法选择性移植，加Moos UI Adapter。比继续叠加样式更易逐页对照，比整体接入DSH运行框架更能保持现有后端和轻量桌面壳。原版组件中的Cordis、HostObservable、原版RPC、Profile及运行框架注入必须替换为Moos类型化视图/命令，不安装或启动DSH服务。依赖变化逐项审查，不能把整个上游monorepo放入应用资源。

## 用户流程与数据契约

1. 启动后显示真实项目与会话，空项目/无会话/无模型/连接中断各有独立空态；不展示样例数据冒充历史。
2. 项目/会话切换保持运行任务、草稿归属与模型选择行为；错误沿用发起选择范围，迟到响应不污染新会话。
3. 输入框接submit/cancel和真实usage，保留权限菜单当前“执行策略尚未接入”的准确边界，不宣称前端按钮已实施权限控制。
4. 运行中显示公开说明和真实工具动作；成功/失败/取消/重启中断分别呈现，工具输出脱敏且限制大小；不伪造推理。
5. 打开右栏不触发新模型请求，不创建第二个终端实例；关闭仅关闭面板，不取消任务或PTY。终端复用现有TerminalDock与原生租约，避免在不同区域重复挂载创建。
6. 插件保留Manifest、Slot和Worker隔离，视觉Token统一不应让插件越权。右侧Slot重新挂载后明确确认哪些贡献可见。
7. 设置真实费用缺失仍显示暂无数据；模型密钥只由用户输入，private/credentials.json本机0700/0600，日志/导出不含密钥，不恢复钥匙串访问。
