# P02.8 受信任内置项目终端

承接已确认P02计划：在对话区下方按需展开原生终端，不恢复右栏，不引入Node/Web服务。保留用户选定的背景、会话卡片、命名与最左设置入口。

## 生命周期与布局

固定受信任内置integration插件dev.moos.terminal贡献composer.leading。第三方本地UI仍为Worker声明式视图，不能取得该原生能力；仅该准确内置ID/entry可用integration类型，私有锁协调命令不在agent_request公开白名单内。设置停用/错误隔离清理所有原生终端，清理失败明确提示重新启用后关闭标签，不宣称进程已结束。

打开面板不启动shell，用户新建后才创建/bin/zsh -f。当前项目最多4个标签，全应用8个。切换项目保留其他项目会话，收起只隐藏；新建、切标签、输入、输出、窗口resize、Ctrl+C、关闭可用。每标签输出最多1MiB、单页16KiB，超出提示截断，界面滚动缓冲2000行；不将原始终端内容写入日志或SQLite。应用重启不恢复进程、不自动重放历史命令，需手动新建；“恢复”在本轮指收起/展开、项目切换后的现有会话重新显示。

使用portable-pty0.9.0和xterm6.0.0/fit0.11.0，前端按需加载。参考官方API：<https://docs.rs/portable-pty/0.9.0/portable_pty/>、<https://xtermjs.org/docs/api/terminal/classes/terminal/>。不加载链接/剪贴板插件，OSC链接不自动打开，renderer为字节流，不解析HTML。PTY非阻塞写入最多4096字节且250ms有界；前端UTF-8分块、排队输入64KiB上限，失败不自动重复提交。读取使用poll等待可读，防止固定睡眠节流；退出状态与读取EOF分别确认，读完尾页后才显示退出码。

## 项目与进程协调

NativeManager从Agent内部取得已登记规范化项目路径和租约，重新canonicalize验证；不能从WebView传cwd、shell、启动参数或环境变量。环境清空后只给固定PATH、TERM、LANG、PROMPT、HOME及临时ZDOTDIR，不继承模型密钥和用户shell启动配置。该终端可运行任意当前账户有权执行的命令，不是OS文件沙箱，用户cd到其他目录后的文件操作不由所选项目锁覆盖，不伪装全盘安全隔离。

Scheduler与现有任务共用规范化目录锁互斥：打开终端必须无该项目运行/排队任务；同项目多个终端允许共用，最后一个退出/关闭后才解除锁，已有智能体任务在此期间排队。其他项目可继续；中断命令不关闭shell、不释放锁。私有租约获取/释放在Rust侧串行，避免多个标签同时退出冲击既有stdio写队列。项目移除先关闭该项目终端，再由服务校验运行任务；不结束其他项目。用户在终端手动运行Git仍使用该项目锁，不提供D01原生Git管理能力。

关闭标签、停用插件、移除项目、正常退出应用会清理登记shell的前台组和当时可追踪的后代，确认shell退出才释放租约。正常退出先关闭Agent调度，再清理终端，避免释放锁时启动排队模型任务。主动setsid/disown等逃逸守护进程无OS进程容器保证；强制SIGKILL App与任意分离守护进程属于P02.9剩余实测范围，不据正常退出宣称已覆盖。

## 验收

- Scheduler：终端占用期间同项目排队、他项目完成，最后租约释放才继续；任务活跃/排队时拒绝新终端，停机拒绝新租约。
- Rust：真PTY、规范cwd、env隔离、UTF-8、尺寸、退出码；Ctrl+C恢复、跨项目访问拒绝、输入上限、输出环形缓冲、标签上限、项目关闭/停机/Drop、自有后代与无关进程隔离；真实Node控制器与NativeManager共用租约和移除保护。
- UI：原生命令无HTTP回退、串行/异常释放，标签新建/关闭、收起不中断、跨项目迟到结果隔离、失败重试，字节流、UTF-8分块和卸载忽略迟到输出；Manifest拒绝第三方伪装integration，既有插件/皮肤回归。
- Mac安装版：真实输入无敏感命令、中文、尺寸、两标签隔离、Ctrl+C与关闭长命令；停用插件、项目移除和正常退出后核对自有进程，保留截图于本机临时目录。只有全部对应测试及实际验收通过并记录后才勾选P02.8，P02.9仍未完成。
