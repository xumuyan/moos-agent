# P02.9：错误归属与默认皮肤状态修正

范围来自E28实际验收遗留问题，不扩展功能。命令错误按发起时projectId/conversationId/providerId归属，选择变化时清除，迟到失败不能显示在另一选择下；本机连接错误继续独立显示，不掩盖服务断连。

默认皮肤按钮也显示“已应用”。预览目标被移除时仅回退到可用预览，不自动保存或应用；皮肤目录变更后沿用既有loadSavedTheme验证与默认样式回退，不把纯视觉样式回退误报为数据丢失。

回归覆盖会话切换清除已显示错误、提交未结束时切到另一项目后迟到失败不污染、已启用本地皮肤从目录消失后的默认标记与预览。完整自动检查和安装GUI分别记录，未验收不提前勾选P02.9。
