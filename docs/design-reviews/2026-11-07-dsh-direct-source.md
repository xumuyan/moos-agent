# P03.7 原版源码移植与图片皮肤验收

范围：按用户“直接抄源码”要求，以固定DSH版本的原样CSS Modules/可复用原语和表现结构替换近似组件。来源与边界见 `docs/third-party/dsh-direct-source-p037.md`。本记录对应从3caa5b1起的同一组合工作区，最终提交通过唯一说明查询，不预造自身哈希。

## 对照与修正

- 44份原版文件与上游固定checkout逐字核对，包括CSS、图标数据、DisclosureRow、UserMessageBubble等；哈希清单覆盖原版与适配文件。
- Sidebar采用原版文件夹/箭头/文字兄弟节点，工作区标题保留原版空搜索席位，不制造未实现搜索；macOS折叠至零宽，使用原版标题栏按钮位置。
- HeroShell只包标题/空body，工作区行、InputBar是同级；清除旧版额外padding。保留Moos标题和图标，实际项目名称位于原版工作区席位。
- 输入框工具行采用原版菜单/SVG、真实模型、权限计划中提示和终端按钮；Lexical由textarea适配。输入框和Portal席位跨hero/active保持同一DOM父级及key，避免终端重建。
- 过程采用原版DisclosureRow/ToolRow/TextShimmer；只用公开事件，保留工具失败和未记录状态，不显示工具载荷代码。修改文件汇总仍只统计确认的编辑工具，不假报shell改动。
- SettingsPanel使用原版Portal/遮罩/布局/焦点栈，保留实际九个设置分区，嵌套Ant弹窗有前台焦点保护。右栏使用原版SidebarRight/DockKit结构，只保留实际三页签。
- 复核发现新控件缺少折叠前锚点、返回按钮被sticky输入区盖住。修复捕获原版展开行/过程按钮；ResizeObserver测量输入区实际高度，返回按钮在其上方16px，覆盖终端增高测试。
- 图片皮肤使用本机Blob、预览、显式应用与效果调整。深色测试图暴露hero/用量对比不足，因此图片开启时增加独立浅色席位；默认原版样式不受影响。
